# 怎样更新这份博客

博客正文保存在仓库的 `content/posts/` 目录，每篇文章是一份 Markdown 文件。

## 一次简单的发布

1. 参考已有文章，新建 `YYYY-MM-DD-slug.md` 文件。
2. 在文件开头填写 `title`、`date` 和 `summary`。
3. 在本地运行构建与检查，再把源码和生成的 `docs/` 一起提交到 main 分支。

```sh
python3 scripts/build.py
python3 scripts/check.py
git add content docs
git commit -m "Add a new note"
git push origin main
```

GitHub Pages 会从 `main` 分支的 `docs/` 目录发布，无需额外的付费服务或部署密钥。

## 写作约定

- 记录已经确认的事实，将计划与结果分开。
- 不把密钥、私人配置或未经许可的信息写进文章。
- 项目软件的许可与博客站点代码许可分别管理。

当前轻量渲染器支持标题、段落、列表、链接、行内代码和代码块；原始 HTML 会转义显示。完整维护说明见[源码仓库](https://github.com/czj44223-cloud/czj44223-cloud.github.io)。
